NoteWorthy Composer Browser Plug-in Sample
Moonlight Sonata

This page demonstrates the use of the <embed> tag to show the Moonlight Sonata sample file in the NoteWorthy Composer Browser Plug-in.

Having trouble viewing this sample?
You might need to download the latest edition of the NoteWorthy Composer
browser plug-in. This plug-in extends the capabilities of your web browser to
include the display, play back, and printing of *.nwc song files created by
NoteWorthy Composer.
