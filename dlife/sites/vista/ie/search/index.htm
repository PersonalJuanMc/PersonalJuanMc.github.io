Быстрый, полный, настраиваемый поиск в Интернете

Поиск
Обозреватель Internet Explorer 7 дает возможность воспользоваться услугами популярных поисковых систем. Встроенная строка поиска в любое время позволяет выполнять поиск в Интернете, не открывая страницу поисковой системы. Результаты поиска показываются в отдельной вкладке. Чтобы быстро сравнить узлы и найти необходимую информацию, откройте результаты в других вкладках. Пользователь может настроить функцию поиска, выбрав популярную поисковую систему в качестве поисковой системы по умолчанию.
